CWC

Campus Wide Companion

A read-only operations layer for a campus-wide Bitfocus Companion deployment: inventory, health, knowledge base, and a dynamic config build engine.

View on GitHub Quick start

Read-only by design

The adapter only issues GET requests to allowlisted Companion paths. No button presses, restarts, imports, or device commands.

Version aware

One adapter handles Companion 4.2.5 (schema 9, classic buttons) and 5.x (schema 12, layered buttons).

Knowledge base

Rooms, devices, modules, protocols, archetypes, and fault playbooks in a searchable index.

Dynamic build

Generate connections, buttons, actions, and variables from a room blueprint, then validate and diff before review.

Advisory AI

Optional OpenAI-compatible copilot grounded in the knowledge base. It has no write tools.

Public-safe data

The public repository ships a synthetic campus with RFC 5737 addresses. Real inventory stays private.
